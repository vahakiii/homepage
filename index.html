How to Set Up GitHub Gist Sync

A Gist is GitHub’s simple way to store text or files online. It works like a private backup for your Start Page data and settings.

Step 1: Create a GitHub Account

If you don't have one, sign up at github.com

Step 2: Generate a Personal Access Token
  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Give it a name like "Start Page Sync"
  3. Set the Expiration to "No expiration" (recommended)
  4. Select only the gist scope
  5. Click Generate token at the bottom
  6. Copy the token immediately (you won't see it again)
Step 3: Save Credentials in Start Page

Click GitHub Credentials in the Sync menu and paste your username + token. Then click Save.

Step 4: Export for the First Time

Click Export to GitHub. This will create a new private Gist and save its ID.

Step 5: Import on Other Devices

On another browser/device, enter the same credentials, then click Import from GitHub. It will pull the latest version.

Step 6: Where to Find Your Gist ID

You can find your Gist ID in these places:

  • In the success popup right after you click Export to GitHub
  • Inside this app: Go to Sync with GitHub → GitHub Credentials
  • On GitHub: Visit gist.github.com, click on your Gist, and copy the long string from the URL
Tip: Your Gist is private by default. Only people with the Gist ID + your token can read it. The Gist ID is saved in your browser after the first export.
